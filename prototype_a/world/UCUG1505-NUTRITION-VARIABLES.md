# 饱腹与整夜睡眠

2026-11-10。饱腹感为0–1状态，新增小球/旧存档缺省为0.6，醒着时每720秒消耗1.0。昏迷与整夜睡眠不消化。原24→20→5网络结构保持兼容，饱腹需求由先天决策和生理层直接执行。

| 食物 | 饱腹增量 |
| --- | --- |
| 原食物（食盆按真实消费量） | 每份0.35 |
| 堂食简餐 | 0.55 |
| 打包简餐 | 0.45 |
| 便当 | 0.75 |
| 零食 | 0.20 |
| 两种医疗包 | 0 |

所有值限制到0–1。能量消耗乘以1−饱腹×0.4，正向精力消耗乘以1−饱腹×0.3，包括做饭、工厂工作、社会生产和巨碑附近的额外精力消耗；恢复量不受减益。饱腹>=0.6时，每秒愉悦增加0.001、舒适增加0.002。饱腹<0.45主动找食物，即使能量很高；食盆进食到能量>0.93且饱腹>=0.9，或库存不足时结束。无食物仍走现有生产补给流程。

夜间先考虑能安全到达的空床；普通工作和配送可以暂停，救援和正在吃饭不会被强制中止。没有可达空床时保留原补能与避险路径，不制造免费床位。抵达床位时才开始整夜锁定，白天小睡跨入夜间也锁定。锁定期间身体静止、不消耗能量/精力/饱腹、不因普通任务而醒来；日出（climate.isNight由真转假）后能量1、疲劳0、舒适1、安心1、愉悦至少0.6，保持真实饱腹和关系，给予120秒原有精力充沛效果。日间小睡仍用原恢复规则。

白天光源恢复在能量>=0.6且疲劳<0.45，或饥饿且食盆有粮时结束。阳光场本身的恢复参数不变。昼夜与季节钟速不变。
