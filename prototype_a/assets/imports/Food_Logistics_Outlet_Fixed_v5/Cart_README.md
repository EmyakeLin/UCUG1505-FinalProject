# 食物配送小推车 · 第二版

用户已认可的圆润陶盆形态，使用 Blender 4.3.2 完成。D=1 场景单位；车头朝 Blender -Y、上方为 +Z，标准 GLB 导出转换到 Three.js +Z 车头、+Y 向上。

## 文件
- source/food_cart_v02.blend：正式可编辑空车，不含舞台、灯光、相机、示意小球或食物。
- models/food_cart_v02.glb：运行时空车，保留各轮、挡板、推垫和 Empty 挂点。
- models/food_cart_v02_display.glb：可选满载展示，四颗 0.7D 食物各自独立，不焊入车身。
- validation/cart_validation.json：实际重新导入 GLB 后的尺寸、UV、有限坐标、Cargo 净空和门轴扫角结果。
- previews/food_cart_v02_*.png：正式满载、空车俯视和开门预览；照明、背景、描边不烘焙到模型。

## 造型与尺寸
这是新重建的连续圆弧奶油色浅陶盆壳、粗圆 U 形陶土口沿、鼓圆轮胎和嵌色轮毂、宽圆边前挡板及饱满低推垫，不是旧版薄板箱体。

实际空车外包 1.800 × 2.200 × 0.850D，轮宽已计入；总根 FoodCart_Root 位于完整占地中心地面，位置/旋转为零，缩放为一。四轮直径 0.45D、轮心高 0.225D，轮心 X=±0.84D、Y=-0.725/+0.375D，各轮原点保留在轮心，局部 X 为转轴。车底板上表面 Z=0.40D，四球中心 Z=0.75D，满载最高约 1.10D。

## 程序接口
- Gate_Pivot=(0,-1.025,0.40)，Gate 是其子物体；正向局部 X 旋转向车前 -Y 翻开。建议使用 0–85°，几何验证覆盖 0–90°。
- Cargo_01…04：X=±0.355，Y=-0.53/+0.18，Z=0.75；同排中心相距 0.71D。
- Push_Contact=(0,1.10,0.50)；Pusher_Center=(0,1.60,0.50)。推垫有实际连接座。
- Unload_Point=(0,-1.90,0.75)，0.7D 食物在此释放不会与打开的挡板相交。

旋转控制要保持 Euler/quaternion 表示一致。Blender 导入 glTF 后节点可能处于四元数模式；验证明确切换到 XYZ 后施加 X 旋转，并逐角度更新依赖关系和世界矩阵。Three.js 也应一致地更新 rotation/quaternion。

四颗 0.7D 球对车体最近距离均约 0.35D（与底面接触），没有通过缩小食物腾空。门板从 0 到 90°每 5°实测，与四轮三角面无相交；报告记录每个角度真实世界边界，90°门板确实向 -Y 展开。以上是静态几何采样/三角网格检查，不是运行时物理测试。

推车在 4D 食盆外停靠，不能驶入约 1.398D 的球用入口。建议直行净宽至少 2.2D，转向空地约 4×4D，再按实际运动测试。水平车厢和开门本身不会自动卸完食物，仍需程序实现逐颗移动/抛送、导航、轮子滚动和碰撞。模型没有实现游戏配送逻辑。
