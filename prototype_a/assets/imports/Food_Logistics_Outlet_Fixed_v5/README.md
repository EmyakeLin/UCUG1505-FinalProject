# 食物物流资产 · 重建版

仅包含工坊、用户认可的第二版推车、原样保留的4D食盆，以及复用0.7D食物粒。

## 使用
- D=小球直径=1场景单位。Blender Z向上、正面-Y；标准GLB转换为Three.js Y向上、正面+Z。
- models中不带display的是运行时空资产；display仅用于展示，食物独立可移除。请勿同时实例化两份。
- source提供可编辑Blender工程；previews为渲染；validation为实际测试记录。预览中的灯光、描边、环境不烘焙进正式资产。
- 材质为普通PBR、网格带UV。程序可自行实现卡通光照和描边。

## 尺度与版本
- 工坊为用户要求“推倒重来”后的全新建模，并按最新指示改为周边连续绿色高围挡，仅保留入口与出货口。用户明确取消旧工坊文字尺寸限制；请以 Workshop_README.md、模型和验证记录为准，不套用旧6×4.5D及通路规格。
- 工坊展示果实按图建模，与共享0.7D球形食物并非完全相同。展示GLB只用于看效果；运行时可选用共享energy_mote并由程序调整缩放和摆放。
- 推车为已认可第二版，空车1.8×2.2×0.85D，满载高1.1D，四轮与门轴独立。
- 食盆保持原文件不变，底盘直径4D、高0.97D，三入口采样净宽约1.398D。推车宽1.8D，停在食盆外，不能驶入入口。
- 工坊与推车的物理装卸、站位可达性和接口高度需要在游戏中校准；新工坊未声明通过旧通行/对接规格。

## 未实现的行为
生产、成长、收获、库存、配送、导航、能量恢复、车轮滚动、开门控制、压垫与装卸都需要游戏代码接入。Empty仅是位置/朝向标记。水平车厢开门不会自动把食物卸出。

车厢底面0.4D与食盆平台0.12D有高度差，挡板不是已校准的连接桥。可通过程序逐颗短程移动或抛送，完整物理自卸需单独测试。静态几何采样不等同完整连续碰撞或运行时寻路测试。

独立GLB保留规范原点；Combined工程仅为一起查看三资产而把根节点横向分开。
