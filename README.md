# UCUG1505 Final Project · 小球世界

这是 UCUG-1505 Creative Coding and Interactive Arts 课程的期末项目。Prototype A 是一个可以离线运行的生态模拟游戏。玩家作为造物主，在固定视野内观察一群小球生活，并通过建造设施改变它们所处的环境。

## 项目理念

最终作品设想为一件互动桌面装置。观众把日常物品放到桌上，俯视摄像头捕捉物品轮廓，将其位置与尺寸一比一投射到屏幕里的微型世界。短暂停留的物品先形成小球需要绕行的障碍，放稳后由多模态模型识别，并转化为留在世界中的建筑，即使物品被拿走，建筑也依然存在。周围的声音也会影响世界的环境。造物主只能通过建造介入，放下物品时无法预知它会变成什么，又会如何改变小球的生活。

作品让观众体验现实中黑箱算法所处的位置。观众想照顾这些生命，也确实有力量改变它们的生活条件，却无法充分了解它们的需求或预见干预的后果。

## Prototype A 的叙事

一群纯真可爱的小球在有限的世界里过着自己的生活。它们会结伴玩耍、休息，也会照顾彼此。严冬将至，能量短缺让它们濒临灭亡。一座供能巨碑从天而降，提供大量能量，让它们得以活下去。此后，支撑生活与文明发展的能源开始污染它们赖以生存的环境。小球逐渐探索怎样在这个世界延续自己的生活，而造物主每一次出于善意的建造，都可能为它们带来转机或加深困境。

当前原型从一个已有供能巨碑和基础设施的世界开始，让玩家体验小球的自主生活、建造对空间的影响，以及昼夜和入冬带来的生存压力。叙事中的巨碑降临演出、污染危机、完整的文明演进与分支结局仍属于后续设计。实体投放、声音输入和模型识别也留待后续装置原型实现。

## 玩法

- **观察小球的生活。** 小球会自行觅食、充能、找床睡觉、学习和交往，也会分工做饭、配送食物或救助虚弱的同伴。打开「小球」查看个体的行为、心情和身体状态。可以暂停观察，也可以在「认知」中查看它们的经历和学习情况。
- **在有限的空间里建造。** 点击「建造」，从固定模板中选择设施，例如小球之家、团团餐厅或医疗救援站。点击地面定位，也可用方向键微调，选好后点击「放在这里」或按 Enter。按 Esc 取消。留意界面提示，为小球保留通路。设施如何被使用，由小球自己决定。
- **观察昼夜和季节的变化。** 入冬后白昼缩短，夜间活动更耗费能量和精力。通过「世界」查看环境、食物和救援情况，也可以用「保存生活」与「读取保存」在同一浏览器中继续这段生活。

## 在本地运行

有私有仓库访问权限时，可克隆项目，也可以在 GitHub 仓库的 **Code → Download ZIP** 下载并解压。

```bash
git clone https://github.com/EmyakeLin/UCUG1505-FinalProject.git
cd UCUG1505-FinalProject
```

用支持 WebGL 的桌面浏览器（如 Chrome 或 Edge）打开本地的 [`prototype_a/living-world.html`](prototype_a/living-world.html)。这是已打包的游戏入口，所需的库和 3D 模型已内嵌，可直接从文件打开。游玩无需安装 Node.js、启动服务器或联网。

如需修改源码后重新打包，安装 Node.js，然后在项目根目录执行下面的命令。打包无需运行 `npm install`，会重新生成 `prototype_a/living-world.html` 和 `prototype_a/life-analysis.html`。

```bash
node prototype_a/world/build.mjs
```

源码和设施规则详见 [Prototype A 开发文档](prototype_a/world/README.md)。AI 协助与修改范围见 [AI 使用声明](AI%20usage%20declaration.md)。
