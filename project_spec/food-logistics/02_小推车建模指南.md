# 小推车：小球配送员的食物车

## 一眼能读懂的动作

一个小球贴在车后低位软垫上，用身体慢慢把车向前顶。四颗暖金色食物在浅车厢里轻轻晃动。车厢前端有一块可放下的低挡板，方便表达卸货。车上没有人类扶手，没有方向盘，也没有把小球绑住的绳子。

配送员仍是普通小球：它会累、会吃饭、会休息。模型不要求新增一种工人身体；工作身份由推车和行为表达。无需另建带手脚的小球、制服或人物骨骼。

## 尺寸建议

| 项目 | 尺寸或要求 |
| --- | --- |
| 空车总尺寸 | 宽 1.8D × 长 2.2D × 高 0.85D；宽包含车轮，长包含后推垫 |
| 车厢内部 | 净宽约 1.45D × 净长约 1.55D；四颗 0.7D 食物按 2 × 2 单层摆放 |
| 车厢底面 | 离地 0.40D；板厚约 0.06D，不与轮轴穿插 |
| 车厢上沿 | 离地 0.85D；浅车厢，满载食物露出上沿 |
| 满载最高点 | 约 1.10D，来自食物顶部 |
| 车轮 | 四个，直径 0.45D；轮宽约 0.09D，圆润厚边 |
| 轮心 | 离地 0.225D；同侧前后轮心距约 1.1D |
| 后推垫 | 宽约 0.9D、高约 0.35D；中心离地约 0.50D，突出后缘约 0.3D |
| 前卸货挡板 | 宽约 1.45D；沿下沿水平轴向外翻，最大约 70°～90° |
| 直行通路净宽 | 建议至少 2.2D；小球通道不自动等于推车通道 |
| 转向空地 | 建议至少 4D × 4D，供车与后方配送球一起转向，之后按实际运动验证 |

1.45D 内宽减去两颗 0.7D 食物后余量较小，建模不要用厚内倒角侵占底部可用面积。可以适度缩小内圆角，或把展示食物间隙交给程序控制。车轮必须算进 1.8D 总宽，不能在 1.8D 车身外再加一对轮子。

## 结构和节点

| 建议节点名 | 建模要求 |
| --- | --- |
| FoodCart_Root | 总占地中心地面原点；含后推垫后再算边界中心 |
| Chassis | 简洁低底盘，可把静态轮轴并入；不需要悬挂系统 |
| Tray | 奶油色浅车厢，陶土色圆角上沿；前方为活动挡板预留开口 |
| Wheel_FL / Wheel_FR / Wheel_RL / Wheel_RR | 四轮分别成对象，原点在各自轮心，旋转轴沿左右方向 X |
| PushPad | 后方低位接触软垫，独立对象，可供程序小幅压缩 |
| Gate_Pivot | 原点在前挡板下沿铰链中心，局部 X 轴为转轴 |
| Gate | Gate_Pivot 的子对象，闭合时封住车厢前端，向车前外翻 |
| Cargo_01 … Cargo_04 | Empty 标记，不是食物网格；位于车厢内四个食物球心 |
| Push_Contact | 推垫外表面接触点的 Empty，约高 0.5D |
| Pusher_Center | 小球中心目标点的 Empty，在 Push_Contact 后方约 0.5D，防止球身穿入推垫 |
| Unload_Point | 挡板外侧食物释放位置 Empty，不与门板实体相交 |

FL 等方向以车头朝 Blender -Y 为准：左侧 -X，右侧 +X。导出到 Three.js 后轮轴仍沿 X，车头朝 +Z，车尾朝 -Z。不要把车轮与车厢 Join 成一张网格。

食品中心距车厢底面为 0.35D，故常态高度约 0.75D。四个 Cargo 点沿左右和前后各对称分布，中心间距至少 0.70D。先在车厢内摆出四个临时直径 0.7D 球确认不穿模，再隐藏或删除临时球，保留 Empty。

## 与 4D 食盆对接

**小推车停在食盆外侧，不驶进食盆。** 4D 是用户新版食盆的尺寸，不是入口净宽；收到模型前不能保证旧入口、围边或平台仍成立。

- 食盆外侧预留配送停车位，吃饭位置与配送位置错开。不要为配合推车去修改用户尚未交付的食盆。
- 推车的前端朝卸货目标，配送球在车尾。食盆旁留足小球离开车尾、走到侧面的空间。
- 前挡板能打开，只表示模型具备卸货动作接口。水平车厢和放下挡板本身不会让全部食物自动滚出；Prototype A 可用逐颗短程滚动或小抛物线移送表现搬运。
- 若需要完整物理自卸，日后另加倾斜车厢或坡道；本次不强制制作复杂机构。食盆高度未知，挡板也不应被当作已对接完成的桥。
- 工厂出口只需对准车厢前端；装车时可以保持挡板闭合，以短距离落入动画表示。推车无需穿过工厂的球用入口。

参考图前挡板的铰链和比例只是造型示意；**实际必须用下沿水平轴向外翻，不按图中可能看似侧铰链的线条制作。** 参考图的比例球也不是精确标尺。

## 外观、动画与交付

奶油色车厢、陶土色上沿与推垫、鼠尾草绿车轮；保持简单大色块。推垫看起来有一点柔软，车体像小球世界里的耐用陶质小工具。食物可用现有 energy_mote.glb 复用，无需为了本指南重新雕刻四个不同食物。

后续程序可以控制四轮滚动、推垫微压、车体轻晃、门板翻开和食物显隐。建模阶段只需分件与正确原点，不强制烘焙动画。普通刚体节点足够，不需要骨骼。

交付 food_cart_v01.blend 与 food_cart_v01.glb，GLB 为空车。若提供满载预览，另导出 food_cart_v01_display.glb 并清楚标记；不要把四颗食物焊进正式空车网格。建模者检查：四轮触地，底盘不穿地，门板旋转不穿前轮，后推垫能被 1D 小球接触，四颗食物均在车厢内，车宽含轮子不超过 1.8D。
