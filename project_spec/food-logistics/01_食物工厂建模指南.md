# 食物工厂：光合食物工坊

## 建筑应该让人看懂什么

这是一座小球自己照料的开放式食物工坊。后部的培养槽积累自然能源，长出圆滚滚的金色食物；小球照料、收获，再把食物集中到前部出货槽，配送员把它们送往公共食盆。它有劳动和等待，但仍然像小球的生活设施。

阳光中心负责自然供能，工坊负责把自然供给转成可保存的食物。食物不是凭空出现的无限能源；日后的产量应受自然输入、培育时间和劳动限制。巨碑可以在后续设计中影响这条生产链，本次建筑不预设巨碑接口，也不添加污染装置。

## 尺寸建议

| 项目 | 尺寸或要求 |
| --- | --- |
| 完整固定建筑占地 | 宽 6D × 深 4.5D；包含出货槽唇边，叶片不超出占地 |
| 建筑最高点 | 不超过 2.4D，来自叶片；没有屋顶 |
| 底板 | 高 0.12D，前方入口做短缓坡或倒角，不能只留直立台阶 |
| 后部培养槽 | 两个，每个外径约宽 2.4D × 深 1.8D；前沿高度约 0.65D |
| 工作垫 | 直径 0.9D；上表面距地面约 0.20D，即高于底板 0.08D；圆滑边缘 |
| 小球通道 | 连续净宽至少 1.3D，入口建议 1.5D；从入口可抵达两槽前沿和工作垫 |
| 出货槽 | 外尺寸约 1.8D × 1.2D；出口净宽至少 0.8D，单颗食物通过 |
| 出货口唇边 | 对接车厢底面约离地 0.40D；最终收模型后再校准 |
| 食物 | 使用现有 energy_mote 的 0.7D 直径作为兼容起点 |
| 外部装车空间 | 码头前至少 2.4D 宽 × 3.6D 深，供车与配送小球停靠；不算建筑本体 |

这座工坊比 4D 食盆稍大，功能从固定俯视镜头中也能被读懂。外部停车区不必做成庞大平台，可以通过地面标记或程序定位实现。

## 平面布局

以下按 Blender 顶视坐标理解，+Y 为后方，-Y 为正面。建筑总边界 X 为 -3 至 +3，Y 为 -2.25 至 +2.25。

- 两个培养槽放在后部，建议中心 X = ±1.4，Y = +1.1。正前方保持可接近，背面不安排必需工作位。
- 工作垫建议中心 X = -0.4，Y = -0.5；它是小球可以用身体压下的低垫，无人类高度的控制台。
- 出货槽放在前右侧，建议中心 X = +1.7，Y = -1.55；外伸唇边也须落在总占地内。出口朝 -Y，推车在建筑外部停靠。
- 入口放在前左侧，建议中心 X = -1.2；入口净宽 1.5D。低围边只作局部点缀，不能把工作垫或培养槽围死。
- 培养槽前方有连续横向通道，工作垫旁有绕行空间。示意图中的围边可按净空要求缩短。

## 形体与零件

| 建议节点名 | 造型与分件要求 |
| --- | --- |
| FoodWorkshop_Root | 地面中心总根节点，所有建筑零件的父级 |
| Base | 奶油色薄底板，大圆角，无厚重高台 |
| Planter_L / Planter_R | 低矮圆角培养槽，奶油上沿、鼠尾草绿下沿；槽内培养基独立材质 |
| Crop_L / Crop_R | 每槽 3～5 片大而厚的叶片，独立于槽体，方便后续轻微摆动或生长缩放 |
| WorkPad_Base / WorkPad_Top | 工作垫底座与活动面分开；活动面可上下移动约 0.04D |
| OutputBin | 陶土色浅槽，留出单颗出货口；不是会自动长食物的食盆 |
| OutputLip | 短、低、宽的出货唇边，与 OutputBin 分件即可，不要求传送带 |
| Decor_Rim_* | 可选的低围边，数量少；不可挡住必需通道 |

出货槽展示 2～4 颗食物即可；视觉食物数量不等于已决定的库存上限。基础 GLB 不合并这些食物。没有复杂机械收割臂，后续可以用小球靠近、轻顶、食物短距离滚落的动画表达劳动。

培养槽上方食物只是展示实例。若单独交展示版，明确命名为 building_food_workshop_v01_display.glb，运行时使用无食物的 building_food_workshop_v01.glb，避免出现无法取走的装饰食物。

## 留给程序的接口

用 Empty 节点标记下列位置，并保留在 GLB 中；标记不应有可见网格。

- Work_L、Work_R：培养槽前方小球的站位，标记落在球心所在高度。小球半径为 0.5D，故站在底板时中心高 0.62D。站位与墙体之间留足半径。
- Work_Pad：压在工作垫上的球心位置，建议高度 0.70D。球须能从边缘平滑上垫。
- Spawn_Food：出货食物球心位置，位于槽内而不是穿进地板。
- Dock_Cart：建筑外装车时的推车根节点位置；停靠朝向使车厢前端靠近出口。此标记在地面，不采用球心高度。
- Queue_Wait：工人等候位置，不占据入口或推车装车区。

工作位供小球自行选择任务使用；不是供观众直接分派工人的按钮。等待作物成熟时，小球可以离开休息、吃饭或社交。建模不需要加入永久工服、工位锁或值班室。

## 最小交付与检查

交付 building_food_workshop_v01.blend 与 building_food_workshop_v01.glb。模型应包含底板、两个培养槽和叶片、工作垫、出货槽及必要 Empty。材料以普通 PBR baseColor 为基础，避免仅在 Blender 节点中成立的复杂效果。

建模者在 Blender 中放入直径 1D 的临时比例球和推车灰模检查：入口能通过，两个培养槽能接近，装车不遮住主入口，最高点不超过 2.4D。交付时删除比例球、展示灯光和相机。图像若与此处尺寸不一致，按本说明建模。
