# 食物工厂、小推车建模指南

版本 v01 · 2026-11-08 · UCUG1505 Final Project / Prototype A

本包用于手工建模或向建模工具传达需求，包含两张新概念参考板、尺寸与拆件说明、可独立使用的建模提示词、原始生图提示词，以及 AI 使用声明。它不包含已完成的工厂或推车模型。

## 先看这三件事

1. D 为小球静止直径；1D = 1 场景单位。用户已经把食盆重新建模为 4D，本包以此为接口条件，不要求修改食盆。食盆的具体入口和边缘高度需收到新模型后再对接。
2. 阳光中心是自然供能设施；食物工厂把自然能源积累为可储存、可运输、可食用的食物。供能巨碑是大量供能、同时造成污染的外来物。工厂不以巨碑存在为开工前提。
3. 除上述已定条件外，工厂 6D × 4.5D、推车尺寸、每车四颗等是本指南的建模建议，不代表已完成游戏数值平衡，也不是已经接入程序的功能。

## 共同美术与交付

- 温柔、圆润、卡通三渲二；奶油色陶质主体、低饱和鼠尾草绿、陶土橙，金黄色食物。与肃杀冷硬的供能巨碑拉开视觉差异。
- 建模保留圆角和大块体积；少量宽浅接缝即可，不堆细小螺丝、复杂管路或高频纹理。食物只是可食用的储能果实，不画电池正负极或插头。
- 描边、阴影与光晕由程序统一处理，不烘焙黑色外壳或地面投影。食物的微弱自发光独立材质，不依赖 Bloom 才能认出。
- 保留 .blend 工程；工厂和空车分别导出 GLB，贴图如有须内嵌。食物和比例小球不合并进建筑或车身。
- Blender：Z 向上，资产正面/车头为 -Y，右侧为 +X；按标准 glTF 导出后，Three.js 为 +Y 向上、+Z 向前。不要再额外旋转补偿一次。
- 每个资产总根节点位于占地中心的地面，变换为位置零、旋转零、缩放一。活动零件在自己的轴心节点下；不要为了统一原点破坏轮轴或门轴。
- 先做一个能读懂功能的灰模，再做圆角和配色。工厂不必做封闭室内、人员装备、骨骼或完整生产动画。

本次仅交付建模参考与资产规范；游戏代码、用户 GLB、既有模型包均未改动。生产、配送、污染及文明叙事的程序实现另行进行。本包不包含 design diary。
